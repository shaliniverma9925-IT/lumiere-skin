LUMIERE SKIN - Frontend storefront project

Folder structure:
- index.html: page structure/content
- css/style.css: styling and responsive layout
- js/script.js: product listing, filters, product details and cart interactions
- images/: reserved for image assets (current product illustrations are CSS-drawn)

How to run:
1. Extract this ZIP folder.
2. Open the Lumiere-Skin folder in VS Code.
3. Open index.html with the Live Server extension, or double-click index.html.
4. Test product filters, product details, add-to-cart, quantity controls and mobile layout.

Note: This is a frontend demo. Checkout is not connected to a real payment/backend service.
